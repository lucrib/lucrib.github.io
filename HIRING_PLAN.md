# Plano para aumentar as chances de contratação

## O que já foi implementado

- Posicionamento mais explícito para Performance & Test Automation Engineer.
- Destaque para Python, Java, backend, APIs e performance engineering.
- Seção de cases baseada apenas em experiências já conhecidas.
- CTA para baixar CV em português ou inglês.
- CVs enxutos e compatíveis com impressão/ATS.
- Bloco com tipos de vaga desejados.
- Links de LinkedIn, GitHub e email com ícones.
- Dados estruturados como `ProfilePage` e `Person`.
- Experiência e evidências reorganizadas para leitura de recrutadores.

## Próximas etapas, em ordem

### 1. Completar as evidências de impacto

Para cada case, adicionar números reais: redução de tempo, redução de falhas, cobertura, volume de usuários, frequência de deploy, defeitos evitados ou tempo economizado.

### 2. Publicar três projetos demonstráveis

Criar ou selecionar projetos públicos que mostrem Python/pytest, Java/Spring Boot e performance/CI. Cada repositório deve ter README, instruções de execução, arquitetura, decisões técnicas e resultados.

### 3. Adicionar recomendações

Selecionar duas ou três recomendações do LinkedIn de gestores, pares ou clientes. Com autorização, publicar nome, cargo, empresa e trecho curto no site.

### 4. Alinhar os canais

Atualizar LinkedIn, GitHub e CV com o mesmo título, resumo e conjunto de palavras-chave. Fixar de três a cinco repositórios relevantes no GitHub e criar um README de perfil. O GitHub recomenda usar o perfil, README e repositórios fixados para apresentar habilidades, experiência e projetos relevantes. [Referência](https://docs.github.com/en/account-and-profile/tutorials/using-your-github-profile-to-enhance-your-resume)

### 5. Definir a estratégia de busca

Escolher de duas a quatro famílias de vaga prioritárias: SDET, QA Automation, Performance Engineer e Backend Engineer. Criar uma versão do CV e uma mensagem de abordagem para cada família.

### 6. Criar uma rotina semanal

- 5 candidaturas realmente alinhadas.
- 5 contatos personalizados com recrutadores ou gestores.
- 1 melhoria em um projeto público.
- 1 publicação técnica curta.
- 1 pedido de recomendação ou indicação.

### 7. Medir conversão

Adicionar um mecanismo simples e respeitoso de métricas: cliques no CV, LinkedIn, GitHub e email. Revisar mensalmente quais páginas e mensagens geram conversas.

### 8. Revisar acessibilidade e SEO

Validar contraste, navegação por teclado, mobile, títulos, descrições e dados estruturados. A marcação `ProfilePage` ajuda mecanismos de busca a entenderem que a página representa uma pessoa específica. [Referência](https://developers.google.com/search/docs/appearance/structured-data/profile-page)
